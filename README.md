## ✨ Fonctionnalités & Raccourcis

- 🎨 **Thèmes Sombre & Clair** : Basculez instantanément avec la touche **`D`**.
- 📌 **Toujours au Premier Plan** : Fixez l'horloge au-dessus de vos fenêtres de travail avec la touche **`T`**.
- 🔲 **Mode Plein Écran** : Activez le mode immersion avec **`F`** ou **`F11`** (sortie avec **`Échap`**).
- 📐 **Redimensionnement Réactif** : Agrandissez ou réduisez la fenêtre, le cadran et les polices s'adaptent automatiquement en conservant les proportions.
- ⏱️ **Mouvement Fluide 30 FPS** : Aiguilles en interpolation continue pour une lecture naturelle et apaisante.
- 🪶 **Zéro Dépendance** : Utilise uniquement la bibliothèque standard de Python (`tkinter`, `time`, `math`).

---

## ⌨️ Commandes Clavier

| Raccourci | Action |
| :--- | :--- |
| **`D`** | Basculer Mode Sombre / Mode Clair |
| **`T`** | Épingler l'horloge au premier plan (Always on top) |
| **`F`** ou **`F11`** | Activer / Désactiver le Plein écran |
| **`Échap`** | Quitter le mode plein écran |
